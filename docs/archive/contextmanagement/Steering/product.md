## Product

1. Create a reusable set of tools to extract text from local markdown files
2. Track source of information
3. Track and then retrieve source material. 
   1. Endnotes
   2. Footnotes
   3. Bibliographic references
4. Place material into a searchable repository

## Features

1. Focus on historical documents
2. Consistent JSON output
3. Web searches to augment results
4. The material shall be broken down into:
   1. events
   2. sub-events
5. The each top-level JSON entries shall have a unique identifier created using ULIDs.
